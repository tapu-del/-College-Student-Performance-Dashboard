# College Student Performance Dashboard

## 📌 Project Overview
This project is an interactive Power BI dashboard designed to analyze college student performance, attendance, and demographics. It helps educational institutions track student progress, identify areas for improvement, and monitor pass/fail rates across different branches and courses.

## 🛠️ Tools Used
* **Power BI Desktop** (Data Visualization, DAX)
* **CSV Dataset** (2,900+ student records)

## 📊 Dashboard Features
* **Modern UI:** Light background with clean white KPI cards and dark blue borders.
* **KPI Cards:** Total Students, Average Marks, Average Attendance, and Total Pass/Fail count.
* **Dynamic Slicer:** Filter the entire dashboard by Course (BA, BBA, BCA, B-Tech, etc.).
* **Visualizations:** 
  - Average Marks by Branch (Column Chart)
  - Attendance by Hostel/Day Scholar (Donut Chart)
  - Student Count by Grade (Bar Chart)
  - Student Distribution by Gender (Pie Chart)
  - Age Distribution by Gender (Column Chart)

## 💡 Key Insights
* The dashboard reveals that average attendance is 55.88%, which indicates a need for better student engagement strategies.
* Marks distribution is fairly consistent across all branches (averaging around 64%).
* Hostel vs Day Scholar attendance is almost perfectly split, showing equal engagement regardless of living situation.
